# **App Name**: WeatherWise

## Core Features:

- Current Conditions Display: Display current weather conditions for a user-specified location (temperature, humidity, wind speed, description, and an icon to visually represent the conditions)
- Hourly Forecast Display: Display an hourly weather forecast (temperature, conditions icon) for the next 24 hours in a horizontally scrollable format.
- 7-Day Forecast Display: Display a 7-day weather forecast, showing daily high/low temperatures and a weather condition icon.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) for a calm, clear sky feel.
- Secondary color: White (#FFFFFF) for clean content presentation.
- Accent color: Orange (#FFA500) for alerts and interactive elements.
- Use a clean, card-based layout to organize weather information.
- Use clear, easily recognizable weather icons (e.g., Sun, Cloud, Rain) from a weather icon pack.
- Subtle animations for loading data and transitioning between sections.

## Original User Request:
Design a comprehensive Weather App that provides users with accurate and timely weather information. The app should include functionality for viewing current weather, hourly forecasts, and extended forecasts for different locations. Focus on an intuitive user interface and seamless user experience that allows users to easily navigate and access various weather features. The app should also include options for severe weather alerts and the ability to save favorite locations for quick access.
